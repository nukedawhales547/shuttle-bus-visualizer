# Team Working Agreements — Devs On-The-Go

## 1. Team Communication Norms
- **Channels:** Core project decisions must live on GitHub Issues or Wiki. Discord or Instagram is used for regular  team chats.
- **Response Times:** Team members must respond to any message directed to them within 24 hours on weekdays.
- **Meeting Etiquette:** Meetings start on time with a clear agenda or topic; the scribe takes down notes and action items.
- **PR Review Tone:** Reviews must be polite, constructive, and actionable.
